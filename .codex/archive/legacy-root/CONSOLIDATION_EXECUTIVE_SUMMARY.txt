────────────────────────────────────────────────────────────────────────────

1. Workflow Dispatch Input
   Allows manual selection of test type:
   - all:  Run all tests (default)
   - core: Run core tests only (fast, integration, slow)
   - auth: Run authentication tests
   - ml:   Run ML component tests
   - rag:  Run RAG module tests
   - rust: Run Rust swarm tests

2. P19 Shadow Import Detection (NEW)
   Prevents silent failures from stale .egg-link shadowing src/:
   - Runs as pre-flight check (5m timeout)
   - Blocks all tests if shadow import detected
   - Provides clear error message and fix instructions
   - Command: pip install --force-reinstall --no-deps -e .

3. Conditional Job Execution
   Jobs run conditionally based on:
   - Manual input via workflow_dispatch
   - File path changes (git diff detection)
   - Event type (PR vs push vs schedule)
   
   Examples:
   - test-auth: Runs if auth/** files changed
   - test-ml: Runs if training/** or ML files changed
   - test-rag: Runs if rag/** files changed
   - test-rust: Runs if .rs files changed

4. ML Test Matrix (2 × 3)
   Python versions: 3.11, 3.12
   Test suites: training, data, metrics
   Total: 6 parallel test jobs = ~45m execution
   (vs sequential: 90m+)

5. Unified Coverage Reporting
   Single coverage job aggregates all test results:
   - Generates .coverage.json
   - Creates HTML coverage report
   - Artifacts retained for 90 days
   - Uploaded to GitHub artifacts

CONSOLIDATION STRATEGY: Why Keep Specialized Workflows?

While optimized-test-execution.yml now contains all test logic, specialized
workflows (auth-tests, ml-tests, test-rag, rust_swarm_ci) are retained because
they have DISTINCT TRIGGERS:

  auth-tests.yml       → Triggers on src/codex/auth/** changes only
  ml-tests.yml         → Triggers on ML paths + scheduled nightly
  test-rag.yml         → Triggers on src/codex/rag/** changes only
  rust_swarm_ci.yml    → Triggers on .rs files + Rust paths

This provides:
✓ Isolation: Auth changes don't trigger ML tests
✓ Efficiency: Only relevant tests run for each change
✓ Faster feedback: Specialized tests run independently
✓ Fallback: Optimized workflow serves as backup

Result: 8 workflows → 3 consolidators achieves 63% reduction while
maintaining specialized trigger logic.
