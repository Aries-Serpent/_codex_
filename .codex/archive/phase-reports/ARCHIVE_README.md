# Phase Reports Archive

## Overview

This directory contains archived phase execution reports from Phases 1-7 and ongoing maintenance reports.

## Structure

- **phase-1-10/**: Completed phase reports (Phases 1-10, historical reference)
- **phase-maintenance/**: Operational and accountability reports

## Navigation

### Finding Phase Reports

1. Determine phase number (e.g., "PHASE_7A_WAVE2")
2. Navigate to corresponding subdirectory
3. Search for filename in that directory

### Common Report Types

- Accountability reports: `phase-maintenance/`
- Phase execution reports: `phase-1-10/`
- Telemetry and evidence: `phase-maintenance/`

## Archival Timeline

- **2026-07-08**: Initial archival during Phase 8.2 cleanup
- **Phase 1-7 files**: Moved from `.codex/` root for space management
- **Keep active**: Phase 8+ files remain at `.codex/` root for current reference

## Retrieval

If you encounter a link to an archived phase report:

1. Check if it's in `phase-1-10/PHASE_[N]/` directory
2. Update links to point to `.codex/archive/phase-reports/phase-1-10/PHASE_[N]/` path
3. Report broken links to documentation team
