## How to Use This Index

### Find a Specific Report

1. **Use Quick Navigation** at the top to jump to a phase
2. **Scan the table** for your report within that phase
3. **Open the file** at `.codex/archive/phases/[FILENAME]`

### Search Across Reports

```bash
# Find all reports mentioning a specific keyword
grep -r "keyword" .codex/archive/phases/

# Find all reports for a specific phase
ls .codex/archive/phases/PHASE_X_*

# Count reports in each phase
for phase in 1 2 3 5 6 7 8 9 B D; do
  echo "Phase $phase: $(ls .codex/archive/phases/PHASE_${phase}* 2>/dev/null | wc -l)"
done
```

### Link to Reports

From documentation files, link to phase reports:


## Archive Maintenance

### Adding New Reports

When new phase reports are completed:

1. Move file to `.codex/archive/phases/[FILENAME]`
2. Add entry to appropriate phase section above
3. Update file count in statistics
4. Commit with message: "docs: Add [PHASE_X] report to archive"

### File Naming Convention

All archived phase reports follow this naming pattern:

```
PHASE_X[_TEAM_Y|_LANE_Z|_TRACK_W][_DESCRIPTOR][_STATUS].{md|txt|json}
```

Examples:
- `PHASE_3_TEAM_4_DEPLOYMENT_CHECKLIST.md`
- `PHASE_7A_WAVE3_LANE31_COMPLETION_REPORT.md`
- `PHASE_D_LANE_11_ML_VALIDATION_RESULTS.json`
