### Q: What is the mutation score and what does it mean?

**A:** Mutation score (88.7%) measures test effectiveness. We introduce controlled code changes (mutants) and verify that tests catch them. 88.7% means tests kill 88.7% of introduced mutations, demonstrating strong bug detection capability.

### Q: Why is exception handling the lowest-performing operator?

**A:** Exception handling is difficult to test because error conditions are intentionally rare in normal flow. Tests often focus on happy paths, leaving error recovery paths under-tested. This is a Phase 3 focus area.
