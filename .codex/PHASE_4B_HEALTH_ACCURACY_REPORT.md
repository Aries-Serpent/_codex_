4. **Data Source Issue**: API returning incomplete data
5. **Aggregation Lag**: Data not yet aggregated from all sources

**Remediation**:
1. Check dashboard `last_updated` timestamp
2. Verify time range used (last 24h vs last 30d)
3. Review metric calculation logic
4. Validate API queries return expected data
5. Check for data aggregation delays

### Issue: Trend Indicator Wrong

**Possible Causes**:

2. **Calculation Error**: Trend algorithm incorrect
3. **Transient Spike**: Temporary deviation masking true trend

1. Collect minimum 7 data points for trend

3. Use 30-day average to filter transient effects
