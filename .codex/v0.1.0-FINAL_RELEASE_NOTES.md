## 🚀 INSTALLATION & DEPLOYMENT

### Installation (Simple Path)

```bash
# Download release
curl -L https://github.com/Aries-Serpent/_codex_/releases/download/v0.1.0-final/codex-0.1.0-final.tar.gz \
  -o codex-0.1.0-final.tar.gz

# Verify checksum
sha256sum -c codex-0.1.0-final.tar.gz.sha256

# Extract
tar xzf codex-0.1.0-final.tar.gz

# Install
cd codex-0.1.0-final
pip install -e .

# Verify installation
python -c "import codex; print(codex.__version__)"  # Should print: 0.1.0-final
```

### Docker Deployment

```bash
# Pull image
docker pull ghcr.io/aries-serpent/codex:v0.1.0-final

# Run container
docker run -it --rm \
  -e CODEX_LOG_LEVEL=INFO \
  ghcr.io/aries-serpent/codex:v0.1.0-final

# Verify
docker run --rm ghcr.io/aries-serpent/codex:v0.1.0-final \
  python -c "import codex; print(codex.__version__)"
```

### Kubernetes Deployment

See `PHASE_7B_OPERATIONS_PLAYBOOK.md` for complete Kubernetes deployment guide.

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: codex-v0.1.0-final
spec:
  replicas: 3
  selector:
    matchLabels:
      app: codex
      version: v0.1.0-final
  template:
    metadata:
      labels:
        app: codex
        version: v0.1.0-final
    spec:
      containers:
      - name: codex
        image: ghcr.io/aries-serpent/codex:v0.1.0-final
        env:
        - name: CODEX_LOG_LEVEL
          value: INFO
        ports:
        - containerPort: 8080
```
