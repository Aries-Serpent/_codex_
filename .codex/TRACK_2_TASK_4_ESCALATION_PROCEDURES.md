## Escalation Paths

### Standard Escalation Chain

```
L1 On-Call
    ↓ (if not resolved in 15 min)
L2 Engineering Manager
    ↓ (if not resolved in 30 min)
L3 Director of Engineering
    ↓ (if not resolved in 1 hour)
CTO/CEO (SEV-1 only)
```

### Time-Based Escalation

- **0-5 min:** L1 attempts fix
- **5-15 min:** Escalate to L2 if not resolved
- **15-30 min:** L2 coordinates broader response
- **30+ min:** Escalate to L3
- **1+ hour:** Escalate to CTO/VP

## Emergency Decision Protocol

When escalation fails:
1. Call emergency line
2. Invoke emergency authority protocol
3. Document emergency decision
4. L1/L2 can make decisions if authority unavailable

---

## Critical Decision Tree

```
Incident Detected
    ↓
├─ Can fix in < 5 min? YES → Fix
├─ Is service completely down? YES → Rollback authorized
├─ Is data corrupted? YES → Contact DBA
└─ NO → Monitor and escalate if ongoing
```
