## Error Handling & Rollback

### Common Failure Scenarios

#### Test Failures
1. Capture stdout/stderr in AfterMath analysis
2. Roll back last test group
3. Isolate minimal reproduction
4. Retry up to 5 attempts with determinism enforced
5. Document and escalate if unresolved

#### Coverage Regression
1. Identify module causing regression
2. Review recent changes to module
3. Add tests for uncovered branches
4. Verify coverage restored

#### CI Timeout/Instability
1. Review test execution times
2. Parallelize slow tests with xdist
3. Mark flaky tests with @pytest.mark.flaky
4. Consider test splitting across jobs

### Rollback Procedure
```bash
# If threshold raise causes CI failure
git revert <commit-hash>  # Revert threshold change
# Fix underlying issues
# Re-attempt threshold raise
```

## Validation Commands Reference

### Coverage Measurement
```bash
# Basic coverage
python -m pytest tests/ --cov=src --cov-report=term

# Detailed missing lines
python -m pytest tests/ --cov=src --cov-report=term-missing:skip-covered

# HTML report
python -m pytest tests/ --cov=src --cov-report=html --cov-report=xml

# Coverage for specific module
python -m pytest tests/cli/ --cov=src/codex/cli --cov-report=term
```

### Test Execution
```bash
# Unit tests only
python -m pytest tests/unit/ -v

# Integration tests
python -m pytest tests/integration/ -v

# Specific test file
python -m pytest tests/cli/test_cli_rag_comprehensive.py -v

# With coverage
python -m pytest tests/ --cov=src --cov-fail-under=30
```

### CI Simulation (Local)
```bash
# Run full test suite as CI would
python -m pytest tests/ -v --tb=short --maxfail=5 --cov=src --cov-report=term
```
