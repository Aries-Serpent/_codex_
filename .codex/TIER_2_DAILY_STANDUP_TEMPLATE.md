## STANDUP SUBMISSION PROCESS

### Submission
1. Coordinator completes standup template (EOD, ~18:00 UTC)
2. Save as: `.codex/TIER_[N]_STANDUP_[YYYY_MM_DD].md`
3. Add to PR or push to branch
4. Post comment in GitHub PR linking to standup

### Review
1. @mbaetiong reviews standup (within 12 hours)
2. Responds with approvals, decisions, or questions
3. Tags standup with decision status (APPROVED/ESCALATION/PENDING)

### Escalation Path
- **Green (All On-Track):** No action required
- **Yellow (At-Risk Issues):** @mbaetiong consultation
- **Red (Blockers/Escalations):** Immediate @mbaetiong escalation
