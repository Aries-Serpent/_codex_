# DevOps Terminology Policy

This document defines terminology conventions for DevOps operations in this repository.

**Status**: Active  
**See also**: [CODEBASE_AGENCY_POLICY.md](CODEBASE_AGENCY_POLICY.md)

## Terminology

- **pre-commit**: Work done before a commit is made (not "before the week")
- **commit**: The act of committing changes to version control
- **session**: A logical unit of agent work within a PR
