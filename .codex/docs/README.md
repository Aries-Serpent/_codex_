## 🎓 Key Concepts Glossary

**Rhizome (Deleuze)**: Non-hierarchical network structure where any point can connect to any other. Opposite of tree structure.

**Actual Occasion (Whitehead)**: Fundamental unit of reality - an event/process, not a thing. Comes into being through concrescence.

**Prehension (Whitehead)**: The way one actual occasion grasps/incorporates past occasions. Active feeling, not passive observation.

**Deterritorialization (Deleuze)**: Breaking fixed patterns/structures to enable creativity. Opposite of territorialization (forming stable patterns).

**Line of Flight (Deleuze)**: Escape route from rigid structure. Not rebellion, but creation of something entirely new.

**Concrescence (Whitehead)**: Process of growing together into unity. How an actual occasion integrates prehensions.

**Event Ontology (Process Phil)**: Reality composed of events/processes, not substances/things. Being = Becoming.

**Temporal Modes**: Different ways of experiencing time - Chronos (clock), Aion (intensive), Duration (lived), Epochal (quantum).

**Assemblage (Deleuze)**: Temporary collection of heterogeneous elements. No essential unity, defined by capacities.

**Creative Advance (Whitehead)**: "The many become one, and are increased by one." Universe constantly creating new actual occasions.
