### For Future AI Agents

**When encountering similar issues**:

1. **SQL Syntax Errors with Comments**

   - Move security comments (`# nosec`, `# type: ignore`) to separate lines
   - Validate with `python -m py_compile`

2. **AttributeError on Module-Level Variables**
   - Check if variable is inside conditional block (`if`, `try`, etc.)
   - Monkeypatch the loader function, not the variable directly
