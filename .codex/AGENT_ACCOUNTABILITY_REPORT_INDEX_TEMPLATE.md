## Data Field Descriptions

| Field | Type | Example | Description |
| --- | --- | --- | --- |
| GROUP_NUM | int | 1 | Group number (1-32) |
| TOTAL_GROUPS | int | 32 | Total number of groups |
| SESSION_ID | string | S228 | Unique session identifier |
| PR_NUM | int | 3790 | GitHub pull request number |
| STATUS | string | complete | Session status (complete, pending, resolved, etc.) |
| TIMESTAMP | ISO 8601 | 2026-03-29T22:19:00Z | Session timestamp |
| SESSION_RANGE | string | S001-S010 | Range of sessions in group |
| DATE_RANGE | string | 2026-03-29 to 2026-03-31 | Date range for sessions in group |
| SUMMARY_SNIPPET | string | Fixed: RP-SC2089, RP-ZIP-SLIP, ... | First 60 characters of summary |

## Navigation Pattern

Each chunk has:

**Header Navigation (Top):**
```
| Direction | Link |
| Previous | [Group NN-1](AGENT_ACCOUNTABILITY_REPORT_SESSION_GROUP_NN-1.md) or (First) |
| Index | [Full Index](../AGENT_ACCOUNTABILITY_REPORT_INDEX.md) |
| Next | [Group NN+1](AGENT_ACCOUNTABILITY_REPORT_SESSION_GROUP_NN+1.md) or (Last) |
```

**Footer Navigation (Bottom):** (Same as header)

This ensures users can:
1. Navigate to previous group (if exists)
2. Jump to index for overview
3. Navigate to next group (if exists)
4. Understand position in sequence (e.g., "Group 5 of 32")

## File Naming Convention

### Chunks
- Format: `AGENT_ACCOUNTABILITY_REPORT_SESSION_GROUP_NN.md`
- NN ranges from 01-32 (left-padded)
- Ensures proper alphabetical sorting
- Examples:
  - `AGENT_ACCOUNTABILITY_REPORT_SESSION_GROUP_01.md` (oldest sessions)
  - `AGENT_ACCOUNTABILITY_REPORT_SESSION_GROUP_15.md` (middle sessions)
  - `AGENT_ACCOUNTABILITY_REPORT_SESSION_GROUP_32.md` (newest sessions)

### Index File
- Format: `AGENT_ACCOUNTABILITY_REPORT_INDEX.md`
- Location: `.codex/` (root of chunks directory)
- Single entry point for navigation

## Usage Examples

### Finding a Specific Session
1. Start at `AGENT_ACCOUNTABILITY_REPORT_INDEX.md`
2. Scan the group table to estimate which group contains your session
3. Click the group link to navigate to that chunk
4. Find your session in the chunk

### Browsing Recent Sessions
1. Start at `AGENT_ACCOUNTABILITY_REPORT_INDEX.md`
2. Click "Latest Sessions" link (usually Group 32)
3. Browse from newest downward
4. Use "Previous Group" link to go back

### Searching Multiple Sessions
1. Use `scripts/ci/session_query.py` for complex queries:
   ```bash
   python scripts/ci/session_query.py --session S310
   python scripts/ci/session_query.py --pr 5060
   python scripts/ci/session_query.py --status complete
   ```

## Size Guarantees

- **Chunk Size:** 3-12 KB per chunk
- **GitHub Render Limit:** 256 KB per file
- **Headroom:** ~240-250 KB per chunk
- **Performance:** Chunks render quickly in browser

## Implementation Notes

### Chronological Ordering
Sessions are ordered chronologically (oldest → newest) within each chunk:
- Chunk 01: Oldest sessions (around 2026-03-29)
- Chunk 32: Newest sessions (around 2026-06-23)

### Date Parsing
Timestamps are extracted from the ISO 8601 format:
- Full: `2026-03-29T22:19:00Z`
- Date only: `2026-03-29`
- Used for "Date Range" display

### Fallback Ordering
If timestamps are missing, session IDs are used for ordering (lexicographic sort).

### Navigation Links
All relative links use `.md` extensions and are relative to chunk location:
- Previous: `AGENT_ACCOUNTABILITY_REPORT_SESSION_GROUP_NN-1.md` (same directory)
- Index: `../AGENT_ACCOUNTABILITY_REPORT_INDEX.md` (parent directory)
- Next: `AGENT_ACCOUNTABILITY_REPORT_SESSION_GROUP_NN+1.md` (same directory)
