## 🔍 Detection Patterns

### 1. P19 Shadow Import Issues (CRITICAL)
**Problem**: Conflicting global/local module state when site-packages versions shadow `src/` versions

**Detection**:
```python
import codex  # May resolve from site-packages instead of src/
```

**Fix**:
```bash
pip install --force-reinstall --no-deps -e .
```

**Example**:
- `coverage_phase5_lane_001.py` — Import isolation test
- Pattern confidence: 85%

---

### 2. @pytest.mark.flaky Annotations (CRITICAL)
**Problem**: Tests marked flaky may mask underlying root causes (P19, timing, non-determinism)

**Detection**:
```python
@pytest.mark.flaky(reruns=3)  # ⚠️ High rerun count
def test_something(): ...
```

**Fix Strategy**:
| Root Cause | Action |
|---|---|
| Network timeout | Keep `reruns=2`, add `reason=` |
| Race condition | Fix timing, remove marker |
| P19 shadow import | Apply P19 fix first |
| Non-deterministic | Seed RNG, remove marker |

**Example**:
- `coverage_phase5_lane_002.py` — 2 flaky markers detected
- Pattern confidence: 95%

---

### 3. Fixture Ordering Issues (HIGH)
**Problem**: Shared fixture state without proper isolation causes test interdependencies

**Detection**:
```python
@pytest.fixture()  # ⚠️ Missing scope=function
def shared_fixture():
    global _state  # Global modification
```

**Fix**:
```python
@pytest.fixture(scope="function")  # ✅ Proper isolation
def isolated_fixture(monkeypatch):  # Use monkeypatch
    # Setup with proper cleanup
    yield
    # Teardown
```

**Example**:
- `coverage_phase5_lane_003.py` — Global state fixture
- Pattern confidence: 80%

---

### 4. Non-Deterministic Randomness (MEDIUM)
**Problem**: Unseeded RNG produces different results each run, causing non-reproducible failures

**Detection**:
```python
import random
value = random.random()  # ⚠️ Unseeded
```

**Fix**:
```python
def test_with_randomness(seeded_rng):
    # RNG automatically seeded via fixture
    value = random.random()  # ✅ Reproducible
```

**Example**:
- `coverage_phase5_lane_002.py` — Test with unseeded RNG
- Pattern confidence: 90%

---

### 5. Timezone-Aware DateTime (MEDIUM)
**Problem**: Naive datetime (no timezone) causes comparison failures across timezones

**Detection**:
```python
from datetime import datetime
now = datetime.now()  # ⚠️ Timezone-unaware
```

**Fix**:
```python
from datetime import datetime, timezone
now = datetime.now(timezone.utc)  # ✅ Timezone-aware
```

**Example**:
- `coverage_phase5_lane_004.py` — 2 naive datetime calls
- Pattern confidence: 85%

---

### 6. File System Path Assumptions (LOW)
**Problem**: String-based paths are platform-specific; fail on Windows/macOS

**Detection**:
```python
import os
path = os.path.join('dir', 'file.txt')  # ⚠️ Platform-dependent
```

**Fix**:
```python
from pathlib import Path
path = Path('dir') / 'file.txt'  # ✅ Cross-platform
```

**Example**:
- `coverage_phase5_lane_005.py` — 3 path operation issues
- Pattern confidence: 75%

## ⚙️ Healing Strategies

### Strategy 1: Import Hardening
Ensures explicit module isolation to prevent P19 shadow imports.

```python
# In tests/conftest.py
@pytest.fixture(scope="function")
def isolated_imports():
    """Fixture for isolated module imports"""
    # Prioritize src/ in sys.path
    src_path = str(Path(__file__).parent.parent / "src")
    if src_path not in sys.path:
        sys.path.insert(0, src_path)
    yield
    # Cleanup
```

**Usage**:
```python
def test_imports(isolated_imports):
    import codex  # Resolves from src/
```

---

### Strategy 2: Fixture Isolation
Independent setup/teardown with no shared state.

```python
@pytest.fixture(scope="function")  # ✅ Function scope
def my_fixture():
    # Setup
    value = setup_state()
    yield value
    # Teardown - runs even if test fails
    cleanup(value)
```

**Key Points**:
- Always use `scope="function"` unless session/module explicitly needed
- Use `yield` for proper cleanup
- Never modify global state
- Use `monkeypatch` for environment changes

---

### Strategy 3: Timeout Tuning
Parametrized per-module timeouts prevent timeout-related flakiness.

```python
# In tests/conftest.py
def pytest_collection_modifyitems(config, items):
    for item in items:
        timeout = 60  # Default
        if "slow" in item.nodeid:
            timeout = 300  # 5 minutes
        elif "fast" in item.nodeid:
            timeout = 10   # 10 seconds

        if not item.get_closest_marker("timeout"):
            item.add_marker(pytest.mark.timeout(timeout))
```

---

### Strategy 4: Seed Randomization
Fixed seeds for reproducible randomness.

```python
# In tests/conftest.py
@pytest.fixture(scope="function")
def seeded_rng():
    """Deterministic randomness"""
    random.seed(42)
    import numpy as np
    np.random.seed(42)
    import torch
    torch.manual_seed(42)

    yield 42
```

**Usage**:
```python
def test_reproducibility(seeded_rng):
    val = random.random()
    assert val == 0.6394267984578837  # ✅ Always same
```

---

### Strategy 5: Platform Abstraction
Use `pathlib.Path` for cross-platform compatibility.

```python
# ❌ Platform-specific
path = "data/test.txt"
with open(path) as f: ...

# ✅ Cross-platform
from pathlib import Path
path = Path("data") / "test.txt"
with path.open() as f: ...
```
