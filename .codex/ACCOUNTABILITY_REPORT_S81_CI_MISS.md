## 🔍 Root Cause Analysis

### Why I Missed It

**Cause 1: Incomplete workflow enumeration**
I queried `list_workflow_runs` by filtering to specific known workflow file names. The `Art_Validation Pipeline` runs workflow ID `190514156` (`validate.yml`) — a workflow I had not previously encountered or explicitly tracked. My query pattern was **name-based, not exhaustive**.

**Cause 2: False confidence from subset pass**
Seeing 4 workflows pass gave false confidence. I did not verify "are there ANY other workflows on this branch?" before declaring.

**Cause 3: Local validation gap**
Running `python tools/validate.py --mode fast` locally said "No tracked changes detected; skipping pre-commit" — because locally there are no uncommitted changes. In CI, `VALIDATE_BASE_REF=main` causes the script to use `git diff --name-only` against merge-base to find all changed files and pass them to `pre-commit`. This critical difference was not accounted for.
