FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Will this break existing telemetry collection?
A: No. New patterns are added to existing PATTERN_KEYWORDS dict.
   Existing 42 patterns remain unchanged.

Q: What if a failure matches multiple patterns?
A: Pattern matching is ordered by specificity. More specific patterns
   are checked first. First match wins.

Q: Can I modify pattern keywords?
A: Yes. Keywords should be empirically validated with historical logs.
   Document changes and re-validate confidence ranges.

Q: What if an agent is unavailable?
A: Fallback chain activates. Each pattern has 2-3 fallback agents
   for escalation. Routing engine tracks fallback activations.

Q: How often should I revalidate confidence ranges?
A: Weekly for first month, then monthly. Use empirical data from
   telemetry collection to refine ranges.

Q: What's the maximum unknown bucket size acceptable?
A: <30% is the goal (~150 unknowns). <20% is stretch goal.
   If >40% persists, escalate for Level-2 pattern research.

Q: Can I add more patterns later?
A: Yes. Use the same structure and validation process.
   Document rationale and confidence ranges.
