## 🔍 Detection Patterns

### P19 Shadow Import (85% confidence)
**Problem**: Module imports from site-packages instead of src/
```python
import codex  # May resolve wrong
```
**Fix**: `pip install --force-reinstall --no-deps -e .`

### Flaky Marker (95% confidence)
**Problem**: Tests marked flaky may mask root causes
```python
@pytest.mark.flaky(reruns=3)
```
**Fix**: Diagnose root cause, remove or tune reruns

### Fixture Order (80% confidence)
**Problem**: Fixtures with shared state and no scope
```python
@pytest.fixture()  # Missing scope
def fixture():
    global state  # Bad pattern
```
**Fix**: Add `scope="function"` and use `yield`

### RNG (90% confidence)
**Problem**: Unseeded randomness produces different results
```python
random.random()  # Unseeded
```
**Fix**: Use `seeded_rng` fixture (seed=42)

### DateTime (85% confidence)
**Problem**: Timezone-unaware datetime fails across zones
```python
datetime.now()  # No timezone
```
**Fix**: `datetime.now(timezone.utc)`

### Paths (75% confidence)
**Problem**: String paths fail on different platforms
```python
os.path.join('a', 'b')  # Platform-dependent
```
**Fix**: `Path('a') / 'b'` (pathlib)

## 🛠️ Healing Strategies

### 1. Import Hardening
Prioritize src/ in sys.path during tests
```python
@pytest.fixture(scope="function")
def isolated_imports():
    # Fixture in conftest.py
```

### 2. Fixture Isolation
Use proper scope and cleanup
```python
@pytest.fixture(scope="function")
def my_fixture():
    setup()
    yield value
    cleanup()
```

### 3. RNG Seeding
Fixed seed for reproducibility
```python
def test_with_randomness(seeded_rng):
    # Automatically seeded
    assert random.random() == 0.6394267984578837
```

### 4. Timezone Awareness
Always use UTC for consistency
```python
from datetime import datetime, timezone
now = datetime.now(timezone.utc)
```

### 5. Path Abstraction
Use pathlib for cross-platform safety
```python
from pathlib import Path
path = Path('dir') / 'file.txt'
```
