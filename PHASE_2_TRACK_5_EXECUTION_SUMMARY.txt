## 🎓 Lessons Learned

### P19 Shadow Import Detection
- Timing of pytest collection phase matters
- Module-level imports execute before sys.path modifications
- Need both `collect_ignore` and hook-based filtering
- Regular audits essential for prevention

### Flaky Test Management
- Document reasons for reruns (not just count)
- Monitor rerun success rates over time
- Link to timing issues or resource constraints
- Distinguish true flakiness from environmental factors

### Test Infrastructure
- Parallel execution requires careful fixture scoping
- Determinism must be enforced at bootstrap time
- sys.path handling needs special care with root/src split
- Legacy compatibility layers can introduce subtle issues
