# Archive Policy Summary (v4, Deprecated)

Variant v4 experimented with more narrative language around archive governance. During consolidation all substantive content was
migrated into the [Canonical Archiving Policy](../canonical-archiving-policy.md) and the accompanying index in this directory.

Retained highlights:

- Governance anchored by CODEOWNERS, ADRs, and provenance attestations.
- Strict append-only handling for `.codex/evidence/archive_ops.jsonl`.
- Expectation of quarterly hygiene runs with documented outcomes.
- Requirement to leave a tombstone stub for every removed artifact.

Consult the canonical policy for the maintained version of these requirements.
