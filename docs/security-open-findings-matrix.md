## Status definitions

- **Already fixed**: remediation notes say the change landed and a targeted validation step was recorded.
- **Partially fixed**: scoped changes landed, but the original artifact is still stale or the rule family was only addressed for a subset of files.
- **Still open**: no closure evidence is recorded yet, or a current artifact still reports an actionable issue.
- **False positive**: the finding was triaged as non-secret/non-exploitable noise and retained only with baseline or exact-line allowlisting.
