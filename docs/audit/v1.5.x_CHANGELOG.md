## Migration Guide: v1.4.0 → v1.5.x

### Breaking Changes

None. v1.5.x is fully backward compatible with v1.4.0.

### Recommended Steps

1. **Enable trend tracking** (optional):
   ```yaml
   # .copilot-space/workflow.yaml
   trends:
     enabled: true
     database_path: "audit_artifacts/trends.db"
     auto_store: true
   ```

2. **Run migrations** (automatic on first use):
   ```python
   from scripts.space_traversal.migrations import run_migrations
   run_migrations(Path("audit_artifacts/trends.db"))
   ```

3. **Store historical data**:
   ```bash
   python -m scripts.space_traversal.audit_runner store-trend
   ```

## API Reference

### TrendDatabase

```python
from scripts.space_traversal.trend_db import TrendDatabase, create_snapshot_from_artifacts

# Initialize database
db = TrendDatabase("audit_artifacts/trends.db")

# Store snapshot
snapshot = create_snapshot_from_artifacts(Path("audit_artifacts"))
run_id = db.store_snapshot(snapshot)

# Query trends
trend = db.get_trend("checkpointing", limit=30)
scores = db.get_latest_scores()
regressions = db.get_regressions(threshold=0.02)
```

### Visualization

```python

from scripts.space_traversal.viz_html import generate_dashboard
```

### Webhooks

```python
from scripts.space_traversal.webhooks import AuditEvent, send_webhook

event = AuditEvent(
    event_type="audit_complete",
    repo_name="my-repo",
    timestamp=time.time(),
    avg_score=0.85,
    capability_count=18,
    regression_count=0,
    details={}
)
send_webhook("https://hooks.example.com/audit", event, secret="my-secret")
```
