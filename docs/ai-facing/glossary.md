# Glossary

> For AI Agents - Last Updated: 2024-12-24

This document defines key terms used in the _codex_ system.

## A

**Agent**
: An autonomous AI system that can perform tasks using tools and reasoning.

**Adapter**
: A component that connects the system to an external service (e.g., Pinecone adapter).

**Audit Trail**
: A chronological record of actions for compliance and debugging.

## C

**Chunking**
: The process of splitting documents into smaller pieces for embedding.

**CoVe (Chain-of-Verification)**
: A technique for verifying factual claims in AI responses.

**Cost Tier**
: A classification of model costs (low, medium, high, very-high).

## D

**Dry Run Mode**
: A mode where the system simulates actions without making actual API calls.

## E

**Embedding**
: A vector representation of text used for semantic similarity search.

**Eval**
: An evaluation that measures system performance against benchmarks.

## F

**Façade**
: An API layer that simplifies access to underlying services.

## G

**GHCR**
: GitHub Container Registry, used for storing Docker images.

## J

**JSON-RPC**
: A protocol for remote procedure calls using JSON.

## L

**LLM**
: Large Language Model, the foundation for AI capabilities.

## M

**MCP (Model Context Protocol)**
: A protocol for connecting AI agents to external tools and data sources.

**Model**
: An AI model used for generating responses (e.g., gpt-4o, o1-mini).

## P

**Pipeline**
: A sequence of processing steps (e.g., RAG pipeline).

**Prompt**
: The input text provided to an LLM to generate a response.

## R

**RAG (Retrieval-Augmented Generation)**
: A technique that enhances LLM responses with retrieved context.

**Rate Limiting**
: Restricting the number of requests within a time period.

**Reasoning Model**
: A model designed for complex multi-step reasoning (e.g., o1, o3).

## S

**Semgrep**
: A static analysis tool for detecting security vulnerabilities.

**System Prompt**
: The initial prompt that defines an agent's behavior and capabilities.

## T

**Token**
: The basic unit of text processed by an LLM (roughly 4 characters).

**Tool**
: A capability that an agent can use (e.g., file reading, web search).

## U

**UV**
: A fast Python package installer used for dependency management.

## V

**Vector Store**
: A database optimized for storing and querying embeddings (e.g., Pinecone).

**Verification**
: The process of checking the accuracy of AI-generated content.

## W

**Workflow**
: A GitHub Actions workflow that automates CI/CD processes.
