# PDA Loop Guide

**Status**: Active  
**PDA**: Plan → Do → Assess

This guide documents the PDA (Plan-Do-Assess) loop used by agents in this repository.

## Overview

Every agent session follows the PDA loop:
1. **Plan**: Load context, identify tasks, define success criteria
2. **Do**: Execute tasks with minimal changes
3. **Assess**: Self-review (5+ iterations), validate results, post follow-up prompt
