# Role-based onboarding

Use the shortest path for the work you intend to do:

| Role | Start here | Primary concern |
|---|---|---|
| [Contributor](CONTRIBUTOR.md) | Repository layout and local validation | Changes under the canonical `src/` boundary |
| [ML engineer](ML_ENGINEER.md) | Dependency profiles and ML packages | Training, evaluation, RAG, and inference |
| [GitHub Actions maintainer](GITHUB_ACTIONS_MAINTAINER.md) | Workflow and governance map | CI behavior, policy gates, and supporting scripts |
| [Agent/session operator](AGENT_SESSION_OPERATOR.md) | Session-state guide | Memory, checkpoints, artifacts, and accountability |
