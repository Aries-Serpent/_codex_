## 📚 Known Limitations

### Phase 9 Known Limitations

1. **Test Collection Time**: Full test discovery takes ~60 seconds (optimization in Phase 10)
2. **Cache Tier 4 (Persistent)**: Not yet implemented (Phase 10 roadmap)
3. **ML-Based Failure Prediction**: Pending data collection (Phase 11+)
4. **GPU-Accelerated Inference**: Requires CUDA setup (Phase 12+)

### Workarounds

| Limitation | Workaround |
|------------|-----------|
| Slow test discovery | Use `pytest tests/agents -k <pattern>` for subset |
| Cache tier 4 unavailable | Use Redis/CDN directly (tier 2/3) |
| Limited ML predictions | Rely on heuristic-based detection (current) |
| No GPU acceleration | Use CPU-only (scaled instances available) |
