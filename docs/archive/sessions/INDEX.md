## Purpose

These reports document execution sessions and their outcomes. They serve as:

- Historical reference for work completed
- Documentation of session results
- Evidence of task completion
- Learning material for future sessions

## Archive Policy

Session reports are moved here once:
1. The session is complete
2. All deliverables are committed
3. No active work references the report
4. Content is historical/reference only
