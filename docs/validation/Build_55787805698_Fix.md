# [Validation]: Fix for failing job 55787805698 (Container Build)

> Generated: 2024-11-19 07:29:05 | Author: mbaetiong

## Summary

The Docker build failed while installing dependencies due to Python version and platform incompatibility, specifically for `ray<3,>=2.9` pulled via codex-ml.

### Symptoms
- Logs show `Requires-Python >=3.8,<3.12` constraint violation
- Error: `No matching distribution found for ray<3,>=2.9` during the venv install step inside the runtime stage
- Build failures in GitHub Actions workflow: Container Build (CPU/GPU)

### Root Cause
1. **Python Version Incompatibility**: The Dockerfiles (both CPU and GPU) were using `FROM python:3.14-slim` for both builder and runtime stages, but the ray dependency requires Python <3.12
2. **Platform Architecture**: The workflow did not specify `platforms: linux/amd64`, so Docker Buildx might select an architecture without necessary prebuilt wheels for ray

## Solution

Pin CPU and GPU Docker images to Python 3.11 in both builder and runtime stages, and constrain Buildx to linux/amd64 to match available wheels.

### Changes Made

#### 1. Dockerfile (CPU variant)
**File**: `Dockerfile`

Changed lines 12 and 47:
```diff
- FROM python:3.14-slim AS builder
+ FROM python:3.11-slim AS builder

- FROM python:3.14-slim AS runtime
+ FROM python:3.11-slim AS runtime
```

Note: The metadata label at line 74 already referenced `python:3.11-slim`, which was correct.

#### 2. Dockerfile.gpu
**File**: `Dockerfile.gpu`

Changed line 15:
```diff
- FROM python:3.14-slim AS builder
+ FROM python:3.11-slim AS builder
```

Note: The runtime stage uses `nvidia/cuda:12.2.2-cudnn8-runtime-ubuntu22.04` which installs Python 3.11 via system packages, so no change needed there.

#### 3. GitHub Actions Workflow
**File**: `.github/workflows/container-build.yml`

Added `platforms: linux/amd64` to both build steps (CPU and GPU) to ensure builds use a platform with available prebuilt wheels:

```diff
       - name: Build CPU image
         uses: docker/build-push-action@v6
         with:
           context: .
           file: Dockerfile
+          platforms: linux/amd64
           target: ${{ steps.set_target.outputs.target }}
           push: ${{ steps.set_target.outputs.should_push == 'true' }}
           tags: codex-ml:cpu-latest
```

```diff
       - name: Build GPU image
         uses: docker/build-push-action@v6
         with:
           context: .
           file: Dockerfile.gpu
+          platforms: linux/amd64
           target: ${{ steps.set_target.outputs.target }}
           push: ${{ steps.set_target.outputs.should_push == 'true' }}
           tags: codex-ml:gpu-latest
```
