## Solution Implemented

### SHIM_INVENTORY.yaml Updates

**Changes**: Updated `whitelist_duplicates` field for all 5 training modules to include both legacy and canonical paths.

**Example Entry** (training.engine_hf_trainer):
```yaml
- module: training.engine_hf_trainer
  legacy_path: training/engine_hf_trainer.py
  canonical_path: src/training/engine_hf_trainer.py
  owner: core-ml-platform
  status: shim
  rationale: "Bridge legacy training to canonical src.* imports during migration."
  deprecation_date: "2026-03-31"
  whitelist_duplicates:
    - training/engine_hf_trainer.py  # ← Added
    - src/training/engine_hf_trainer.py  # ← Added
  notes: "Identity assertions allowed under SHIM_IDENTITY_STRICT env in CI. Canonical shim forwards to legacy implementation."
```

**Pattern Applied**: Same update for all 5 modules (engine_hf_trainer, functional_training, data_utils, checkpoint_manager, config)
