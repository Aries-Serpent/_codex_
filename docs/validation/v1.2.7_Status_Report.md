## Rollback Procedures

### For Patch Reversions

```bash
# Identify commit SHA
git log --oneline | grep "patch 000X"

# Revert specific patch
git revert <commit-sha>

# Or restore from backup
git checkout HEAD~1 -- path/to/file
```

### For Refactor Batches

```bash
# AST tool creates .bak files
ls -la path/to/changed/*.bak

# Restore if needed
for f in *.bak; do mv "$f" "${f%.bak}"; done

# Or git revert
git revert <batch-commit-sha>
```
