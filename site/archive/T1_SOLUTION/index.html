    2. noxfile.py¶

    Modified: tests session to enforce coverage

    @nox.session(name="tests", python=PY_VERSIONS)
def tests(session: nox.Session) -> None:
    """
    Baseline test session with coverage enforcement.
    """
    _choose_python(session)
    _install_requirements(session, REQ_DEV)
    _show_vendor_scan(session)
    session.run(
        "pytest",
        "--cov=src",
        "--cov=training",
        "--cov-report=term-missing",
        "--cov-report=xml",
        "--cov-fail-under=70",
        "-m",
        "not requires_torch",
        external=True,
    )

    Benefits: - Enforces 70% coverage threshold in CI - Generates coverage reports (terminal + XML) - Explicitly includes src/ and training/ packages - Maintains marker-based test filtering

    4. src/utils/sanitize.py¶

    Created: Prompt sanitization utility

    def sanitize_prompt(prompt: Optional[str]) -> str:
    """
    Escape a prompt string for safe HTML embedding / display.
    Returns empty string for None; escapes <, >, &, ", '
    """
    if prompt is None:
        return ""
    escaped = html.escape(str(prompt), quote=True)
    escaped = escaped.replace("'", "&#x27;")
    return escaped

    Benefits: - Prevents XSS attacks when prompts rendered to HTML - Minimal dependency (uses stdlib html module) - Clear documentation about limitations - Easy to extend/replace with bleach later

    5. cli/inference.py¶

    def run_inference(prompt: str) -> tuple[str, str]:
    """Placeholder inference with sanitized preview."""
    safe_preview = sanitize_prompt(prompt)

    return safe_preview, result

    Benefits: - Demonstrates sanitization usage - Safe prompt echoing for user feedback - Model receives original prompt (semantics preserved) - Easy to integrate with real inference backend
