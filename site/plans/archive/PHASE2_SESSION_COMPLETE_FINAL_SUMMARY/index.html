    Lessons Learned - Session Insights¶

    Strategic Insights¶

    1. Iteration Size Matters
    2. Sweet spot: 5-15 tests per iteration
    3. Too small: High overhead
    4. Too large: Difficult to debug

    5. Optimal: 8-12 tests per iteration

    6. Coverage Correlation

    7. Equation tests: 0-0.05% coverage/test
    8. Unit tests: 0.05-0.3% coverage/test
    9. Integration tests: 0.5-1.5% coverage/test

    10. Strategy: Prioritize integration tests for coverage ROI

    11. API Design Patterns

    12. Always support old + new parameters
    13. Use __post_init__ for complex aliasing
    14. Optional required fields > breaking changes
    15. Result: Zero migration pain

    Technical Insights¶

    1. Dataclass Benefits
    2. Auto __init__ reduces boilerplate
    3. Type hints improve IDE support
    4. __post_init__ enables flexible initialization

    5. Tradeoff: Must handle mutable defaults carefully

    6. Parameter Aliasing Strategy 

      # Pattern that works well:
def method(self, new_param=None, old_param=None):
    if old_param and not new_param:
        new_param = old_param
    # Use new_param throughout

    7. Union Types for Flexibility 

      # Enables polymorphic usage:
field: Union[str, Any] = ""
# Accepts both specific and general types
