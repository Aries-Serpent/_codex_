    Decoder Module Priority Order¶

    From scripts/security/copilot_token_decoder.py:

    1. CODEX_GHP_TOKEN_CONFIG (Combined AES - most secure)
    2. CODEX_GHP_TOKEN_AES_CIPHERTEXT + CODEX_GHP_TOKEN_AES_KEY (Separated AES)
    3. CODEX_GHP_TOKEN_BASE64 (Simple encoding - recommended for simplicity)
    4. CODEX_GHP_TOKEN_HEX (Alternative encoding)
    5. GITHUB_TOKEN or GH_TOKEN (Fallback - plaintext)

    Verification Checklist¶

    Use this checklist to verify your secrets/variables configuration:

    Required for Copilot Operations¶

    • CODEX_GHP_TOKEN_BASE64 or CODEX_GHP_TOKEN_CONFIG set
    • GITHUB_TOKEN available (auto-provided)
    • CODEX_AGENT_NAME variable defined
    • Token encryption tool tested: python3 scripts/security/token_encryption_tool.py --help
    • Token decoder tested: python3 -c "from scripts.security.copilot_token_decoder import CodexTokenDecoder"

    Required for AI/ML Features¶

    • GITHUB_CODEX (OpenAI API key) set
    • OPENAI_API_KEY set (if using direct OpenAI)
    • PINECONE_API_KEY set (if using vector storage)
    • ENABLE_LIVE_TESTS set (for integration tests)

    Required for Security Tools Bootstrap¶

    • CODEX_SECURITY_ENCRYPTION_TOOL_B64 variable set
    • CODEX_SECURITY_DECODER_MODULE_B64 variable set
    • CODEX_SECURITY_ADMIN_GUIDE_B64 variable set
    • CODEX_SECURITY_MANIFEST_JSON variable set

    Optional/Advanced¶

    • CODEX_MASTER_KEY (for future encryption features)
    • GITLEAKS_LICENSE (if using Gitleaks Pro)
    • Organization-level secrets configured
    • Environment-specific secrets (dev/staging/prod)

    Important Notes¶

    Security Considerations¶

    1. Never Commit Secrets: All secrets listed above should ONLY be stored in GitHub Settings Secrets
    2. Token Rotation: Rotate CODEX_GHP_TOKEN_* secrets every 90 iterations
    3. API Key Rotation: Rotate OPENAI_API_KEY and PINECONE_API_KEY quarterly
    4. Access Control: Limit repository admin access to trusted users only
    5. Audit Logs: Regularly review secret access logs in repository settings

    Variable Naming Conventions¶

    • Secrets: CODEX_*, GITHUB_*, OPENAI_*, etc.
    • Variables: CODEX_* prefix for codex-specific variables
    • Environment: GITHUB_* for Actions-provided variables

    Compatibility¶

    All variables listed are compatible with: - GitHub Actions workflows - token_encryption_tool.py (v2.0) - copilot_token_decoder.py (v2.0) - security-tools-bootstrap.yml workflow - All agent workflows in .github/workflows/
