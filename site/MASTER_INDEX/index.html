    Document Metadata¶

    All documentation should include: - Purpose: What this document covers - Audience: Who should read this - Last Updated: Date of last major update - Version: Semantic version - Status: Active, Deprecated, Archived

    Maintenance¶

    Update Process¶

    1. Update the relevant canonical document
    2. Update this index if structure changes
    3. Check for broken links per 4-5 commit cycles
    4. Archive obsolete documentation (don't delete)

    Archived Documentation¶

    Obsolete docs moved to archive/ with redirect notice.
