# codex-ml-evaluation

Dependency-free evaluation contracts with a small runner and lazy adapters for
the existing `codex_ml` metric registry. Importing this package does not import
PyTorch, Transformers, Datasets, or the monolith.

## Installation

This alpha package is not published on public PyPI. From the repository root,
install it from the checked-out source tree:

```console
python -m pip install ./packages/evaluation
```
