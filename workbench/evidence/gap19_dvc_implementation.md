## CI Job: dvc_pipeline

```yaml
dvc_pipeline:
  name: DVC Pipeline Reproducibility Check
  needs: cost-gate
  steps:
    - dvc repro --no-commit --dry  # validates pipeline DAG without running
    - dvc status --json > workbench/evidence/dvc_status.json
    - Uploads artifact dvc-status-{run_number}
```

The `--dry` flag ensures CI never blocks on missing data files while still
validating that the pipeline definition parses and the stage dependency
graph is structurally correct.
