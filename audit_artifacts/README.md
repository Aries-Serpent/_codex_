# Audit Artifacts Directory

This directory contains intermediate JSON artifacts generated by the Copilot Space Traversal audit pipeline.

## Contents

| File | Stage | Description |
|------|-------|-------------|
| `context_index.json` | S1 | Complete file index with paths, extensions, sizes, and SHA hashes |
| `facets.json` | S2 | Domain-clustered file groups based on regex patterns |
| `capabilities_raw.json` | S3 | Detected capabilities from static rules and dynamic detectors |
| `capabilities_scored.json` | S4 | Scored capabilities with component breakdowns and weights |
| `gaps.json` | S5 | Low-maturity capabilities below threshold (< 0.70) |

## Usage

These artifacts are automatically generated by:
```bash
python scripts/space_traversal/audit_runner.py run
```

To regenerate a specific stage:
```bash
python scripts/space_traversal/audit_runner.py stage S4
```

## Notes

- **Do not manually edit** these files - they are regenerated on each audit run
- Artifacts include SHA256 hashes for integrity verification
- The final manifest (`audit_run_manifest.json`) references all artifact hashes
- Artifacts are excluded from git by default via `.gitignore` patterns
