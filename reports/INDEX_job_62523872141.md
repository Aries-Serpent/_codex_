## Related Issues

### Similar Patterns to Watch
- Module-level `pytest.importorskip()` in conftest.py files
- Any utility files with `test_` prefix in `tests/` directory
- Package `__init__.py` files that import from test modules

### Prevention Recommendations
1. ❌ Never name utility modules with `test_` prefix inside `tests/`
2. ✅ Use clear utility names: `utils.py`, `helpers.py`, `fixtures.py`
3. ✅ Keep test package `__init__.py` files minimal
4. ✅ Add collection timeout to CI: `timeout-minutes: 2`
5. ✅ Run `pytest --collect-only` as a CI gate before full test execution
